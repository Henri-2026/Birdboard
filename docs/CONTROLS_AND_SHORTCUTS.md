# Bảng Tra Cứu Thao Tác Chuột & Phím Tắt (`CONTROLS_AND_SHORTCUTS.md`)

Tất cả phím tắt và thao tác chuột trong **Birdboard** đều có thể tùy biến lại theo thói quen cá nhân tại `Click chuột phải -> Settings -> Keyboard & Mouse`. Dưới đây là cấu hình mặc định:

---

## 1. Điều Hướng Khung Nhìn & Cửa Sổ

| Thao tác | Cách thực hiện mặc định |
| :--- | :--- |
| **Mở Menu Kính Mờ Penart** | `Click Chuột Phải` tại bất kỳ đâu |
| **Pan (Trượt mặt bảng Canvas)** | `Giữ Chuột Giữa + Kéo` |
| **Zoom (Phóng to / Thu nhỏ quanh trỏ chuột)** | `Lăn Con Lăn Chuột` hoặc `Ctrl + Chuột Giữa + Kéo` |
| **Di chuyển cửa sổ không viền** | Nắm kéo dải mép trên cùng cửa sổ hoặc bấm `Ctrl + M` |
| **Thay đổi kích thước cửa sổ** | Kéo trực tiếp tại 4 cạnh hoặc 4 góc cửa sổ |
| **Đóng / Thu nhỏ / Phóng to nhanh** | Cụm 3 chấm tròn ở góc trái trên cửa sổ |
| **Xem vừa khít toàn bộ bảng (`Fit Scene`)** | Phím `1` |
| **Xem vừa khít ảnh đang chọn (`Fit Selection`)** | Phím `2` hoặc `Nhấp đúp chuột trái` vào 1 ảnh (nhấp đúp lần nữa để lùi lại) |
| **Luôn nổi trên cùng (`Always On Top`)** | `View -> Always On Top` |
| **Toàn màn hình (`Fullscreen`)** | `F11` |
| **Đổi chế độ Sáng (`#E9EAEC`) / Tối (`#1A1A1D`)** | `Settings -> Settings -> Appearance & General -> Canvas Theme` |

---

## 2. Thao Tác Với Hình Ảnh & Ghi Chú

| Thao tác | Cách thực hiện mặc định |
| :--- | :--- |
| **Thêm ảnh vào bảng** | Kéo thả file từ ngoài vào, `Ctrl + V` từ Clipboard, hoặc `Insert -> Images` |
| **Thêm ghi chú chữ (`Text Note`)** | `Ctrl + T` (Nhấp đúp vào chữ để sửa nội dung) |
| **Chọn nhiều ảnh** | Kéo khung chọn trên nền trống hoặc giữ `Ctrl + Click` |
| **Chọn tất cả / Bỏ chọn tất cả** | `Ctrl + A` / `Ctrl + Shift + A` |
| **Phóng to / Thu nhỏ ảnh** | Kéo 4 góc của khung chọn |
| **Xoay ảnh (`Rotate`)** | Kéo vùng bên ngoài 4 góc khung chọn (giữ `Ctrl` hoặc `Shift` để bắt góc mỗi `15°`) |
| **Lật ngang / Lật dọc (`Flip`)** | Phím `H` / Phím `V` (hoặc click vào cạnh khung chọn) |
| **Cắt cúp ảnh không mất gốc (`Crop`)** | Chọn 1 ảnh rồi bấm `Shift + C` (`Enter` để xác nhận, `Esc` để hủy) |
| **Hút mã màu (`Sample Color`)** | Phím `S` rồi click vào điểm ảnh (tự copy mã HEX vào Clipboard) |
| **Xem trắng đen (`Grayscale`)** | Chọn ảnh -> `Images -> Grayscale` |
| **Khôi phục biến đổi gốc (`Reset All`)** | Phím `R` |

---

## 3. Sắp Xếp & Đồng Bộ Kích Thước Hàng Loạt

| Thao tác | Phím tắt mặc định |
| :--- | :--- |
| **Xếp khít diện tích tối ưu thành khối vuông (`Arrange Optimal`)** | `Shift + O` |
| **Chỉnh khoảng cách khe hở giữa các hình trực quan (`Arrange Gap...`)** | `Shift + G` *(hoặc `Arrange -> Arrange Gap...`)* |
| **Đưa các ảnh về cùng Chiều cao (`Normalize Height`)** | `Shift + H` |
| **Đưa các ảnh về cùng Chiều rộng (`Normalize Width`)** | `Shift + W` |
| **Đưa các ảnh về cùng Diện tích (`Normalize Size`)** | `Shift + S` |
| **Đưa ảnh lên lớp trên cùng / xuống dưới cùng** | `PgUp` / `PgDown` |

---

## 4. Quản Lý File Dự Án

| Thao tác | Phím tắt mặc định |
| :--- | :--- |
| **Tạo bảng mới (`New Scene`)** | `Ctrl + N` |
| **Mở file bảng (`.bee`)** | `Ctrl + O` (hoặc `Ctrl + 1..9` cho các file mở gần đây) |
| **Lưu bảng (`Save` / `Save As`)** | `Ctrl + S` / `Ctrl + Shift + S` |
| **Hoàn tác / Làm lại (`Undo` / `Redo`)** | `Ctrl + Z` / `Ctrl + Shift + Z` |
